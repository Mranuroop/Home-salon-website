💄 Premium Home Salon & Beauty Services

A modern, elegant, and responsive home salon website designed to showcase beauty services with premium styling, smooth animations, and an attractive user experience.

✨ Features

- 🎨 Modern and premium UI/UX design
- 💫 Attractive 3D animations and visual effects
- 💇 Beauty services showcase
- 🖼️ Gallery section
- ⭐ Customer reviews section
- 📱 Responsive design for mobile, tablet, and desktop
- 📲 Social media integration
- 💬 Contact and booking options

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

🎯 Project Goal

The goal of this project is to create a professional online presence for a home salon, showcase beauty services, and make it easier for customers to explore services and get in touch.

🚀 Getting Started

1. Clone this repository:
   git clone YOUR_REPOSITORY_URL
2. Open the project folder.
3. Open "index.html" in your browser.
